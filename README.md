# PMJ Industrial - Landing Page

Landing page para PMJ Industrial, fabricante de cajas de plástico corrugado y soluciones de empaque industrial.

## Características
- Diseño responsivo y moderno.
- Integración con WhatsApp.
- Teléfono clicable en el header.
- Sección de Preguntas Frecuentes (FAQ) optimizada para SEO.
- Configuración lista para Google Ads.

## Tecnologías
- HTML5 / CSS3 (Vanilla)
- Font Awesome 6.0
- Google Fonts (Outfit, JetBrains Mono)
